通过独立发现、证据审查和保守发布，维护适合 Shadowrocket 的本地广告与追踪过滤配置。

## 公开范围与使用目标

任何人都可以下载未来或已发布的正式配置，无需访问私有开发仓库。后台代码、研究数据库、原始来源、Agent 提示词、审核证据和密钥保持私有；这个公开仓库仅用于批准后的发行文件与项目状态。

配置的设计目标是本地拒绝经过验证的精确广告/追踪主机，正常请求默认直连，不配置远程代理服务器，不要求额外证书或 HTTPS 解密。登录、支付、验证码、银行、视频和搜索兼容性是发布门槛。域名过滤无法天然处理与正常内容共用主机的所有广告，本发布页不承诺全网覆盖或 90% 拦截率。独立评测应另外披露范围、基线、方法和真实结果。

若仓库已开放 Issues，可提供：版本 ID/配置 SHA-256、iOS 与 Shadowrocket 版本、出现故障的功能、可安全公开的精确主机名，以及启用/关闭规则后的对照结果。请勿上传密码、cookie、访问令牌、支付详情、完整浏览历史或含身份参数的 HAR。涉及个人信息时只提交脱敏复现。
